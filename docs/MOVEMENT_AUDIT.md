# Аудит перемещений (этап 12.B)

Каждое место, где до этапа 12 что-то меняло положение скачком, и решение.
Общий механизм — `Mover` (клетка, путь, доля шага, профиль движения из
`data/movement/*.tres`), ходьба — `MovementSystem.advance` раз в сутки, пути —
`Pathfinder` (регионы → клетки, море — через гавань). Мгновенно — только
допустимые телепорты из `data/teleports/*.tres` через `MovementSystem.teleport`
(запись в `World.teleports`, вспышка на карте); `tests/movement_test.gd`
проверяет, что за сутки никто не сдвигается дальше `max_cells` своего профиля.

| Где было | Что | Решение |
|---|---|---|
| `ArmySystem._move` | армия «шагала» центр региона → центр региона раз в месяц (`eta`) | ходьба по клеткам каждые сутки (профиль `army`: рельеф, дороги, броды, зима, чужая земля) |
| `ArmySystem.create` | армия появлялась в центре региона | **появление** (`spawn`): собирается в столице, флот — у гавани; Бог ставит в клетку клика (`god`, со вспышкой) |
| `ArmySystem._land` | десант через `SAIL_DAYS` оказывался в регионе цели | путь: до своей гавани пешком → морем (`sea_speed`) → высадка в береговой клетке; перехват флотом — при высадке |
| `ArmySystem._retreat` | отход на 3 региона «скачками» | путь к ближайшему своему городу; отступающих можно настичь |
| `ArmySystem` (конец войны) | армии исчезали | идут домой (`home`) и распускаются там (не дольше 120 суток) |
| битвы | «в регионе раз в ход войны» | встреча на карте: ближе `CONTACT` — битва в этой клетке (рельеф поля боя помогает хозяевам земли), в пределах дозора — идут навстречу, во время перерыва между битвами стоят друг против друга (долгое противостояние — слабый отходит), броды и перевалы — по одной колонне, «враг у ворот» — ополчение выходит навстречу |
| `PirateSystem._move` | пираты «перескакивали» к другому порту | плывут морем к новой гавани, грабят по прибытии |
| `HeroSystem._move` | `hero.cell = случайная клетка соседнего края / цели / вожака / супруга / врага` | решение раз в месяцы, дальше ходьба (профиль `hero`); за море — через гавань; спутники отряда и супруги **следуют** за вожаком (путь, а не копия клетки); мститель идёт по следу |
| `HeroSystem._move` (цель за морем) | «дальше по суше не пройти — плывёт» = прыжок к цели | путь до гавани → морем → берег → цель; нет пути — цель брошена |
| `Fate` (возвращение героя) | `hero.cell = клетка` | **допустимый телепорт** `fate` (воля Судьбы, дымка) |
| `HeroSystem.spawn`, рождения в роду | появление в крае | **появление** (новый юнит) |
| `PlayerSystem._travel_step` | герой игрока «шагал» регион за регионом | ходьба по клеткам; по краям пути — только отметки |
| `PlayerEncounters` (бегство) | `h.cell = клетка соседнего края` | бежит туда по карте |
| `PlayerWorld.join_army` / служба | `h.cell = a.cell` каждый месяц | идёт к войску и следует за ним |
| `PlayerWorld.capture` | пленника «переносило» в столицу | ведут пешком под конвоем |
| `PlayerSystem` (позвать в отряд) | `c.cell = h.cell` | спутник идёт к вожаку (`follow`) |
| `CaravanSystem` | караван «шёл» по месяцам, на карте — по прямой между городами | идёт по клеткам дороги (`RoadSystem` → `MovementSystem.road_cells`, профиль `caravan`), морем — по воде; засада там, где он идёт (чудовища, кочевники рядом); зараза едет с караваном (`DiseaseSystem.carry`) |
| `DealSystem.propose` | сделка заключалась мгновенно | **посол** (`Agent`, профиль `envoy`) идёт из столицы в столицу; условия — на день прихода |
| `SpySystem.run` | операция — мгновенно | **лазутчик** (`Agent`) идёт к столице цели; операция — по приходе |
| `MercSystem._hire` | `m.cell = столица нанимателя` | отряд идёт к нанимателю |
| `TribeSystem._wander`, `_meet_state` | `t.cell = центр соседнего края` | кочует по карте (профиль `tribe`); край племени — тот, где оно идёт |
| `LairSystem._raid` | великое чудовище «оказывалось» в краю набега; набег мгновенный | чудовище (или ватага) идёт в край набега, бьёт по приходе; ватага возвращается, великое остаётся бродить |
| `LairSystem._month` (рельеф) | логово «переносило» к центру края | гнездо — к центру края (место, не юнит); чудовище на воде — **допустимый телепорт** `terrain` на берег |
| `GodTools.create_army` | армия в регионе | армия в клетке клика — **допустимый телепорт** `god` |
| `Simulation._portals` | легионы бездны пополняют армию демонов | сила, не юнит — без изменений |

## Допустимые телепорты (`data/teleports`)

| id | Когда | Эффект |
|---|---|---|
| `spawn` | новый юнит появляется на месте рождения | — (рождение, не перемещение) |
| `portal` | врата бездны (легионы) | вспышка |
| `fate` | Судьба возвращает героя | дымка |
| `god` | инструменты Бога ставят юнит в клетку | вспышка |
| `terrain` | земля ушла из-под юнита (Бог, пучина) — на ближайший берег | дымка |

## Что не юнит и осталось «мгновенным»

Сила армий государства (`Nation.army`), население, вера, культура, языки,
влияние держав — величины, а не фигуры на карте; они меняются по своим
правилам, как и прежде. Поветрие переходит из края в край по соседству и
морем (половину «дорожного» пути теперь везут караваны).
